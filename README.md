### Retrieval Design

Text and visual retrieval are maintained independently because embeddings generated by unrelated text and vision models occupy different representation spaces.

Raw similarity scores from those spaces should not be assumed to be directly comparable.

Ranked retrieval results can instead be combined using techniques such as **Reciprocal Rank Fusion (RRF)**.

CLIP is used for semantic text-to-image retrieval rather than being represented as a general-purpose vision-language reasoning model.

## Production Engineering Principles

VENU.OS is built around several engineering principles:

**Ground before generation**

Relevant portfolio evidence is retrieved before an answer is generated.

**Separate heterogeneous retrieval spaces**

Text and visual representations are not treated as though their raw similarity scores belong to the same embedding space.

**Expose evidence**

AI-generated portfolio answers are accompanied by the retrieved evidence used to construct them.

**Prefer measurable claims**

Benchmark interfaces avoid presenting invented performance numbers where measured results are unavailable.

**Design for deployment**

The production architecture favors reliable deployment behavior over unnecessary infrastructure complexity.
